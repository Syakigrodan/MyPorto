# MyPortofolio

Proyek portofolio pribadi yang dibangun menggunakan framework Laravel untuk menampilkan daftar karya, proyek, serta informasi profesional saya.

---

## 🚀 Fitur Utama
* Desain antarmuka yang responsif dan modern.
* Manajemen data proyek secara dinamis.
* Dibangun dengan struktur kode yang bersih dan terstandarisasi.

---

## 🛠️ Persyaratan Sistem
Sebelum menjalankan proyek ini, pastikan komputer Anda telah terinstal:
* PHP (versi 8.2 atau yang disarankan)
* Composer
* Node.js & NPM
* Git
